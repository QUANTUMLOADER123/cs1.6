# Превью меню

`menu_preview.png` — симуляция раскладки меню `skeethook_1_6` (rage-таб),
построенная по реальным координатам из `src/features/sh_menu.cpp`.

Симуляция нужна потому, что DLL работает только на Windows с загруженным
`client.dll` (CS 1.6). Скрипт рендера проверяет:

- сетку (row = 20, colw = 210, слайдеры одной ширины);
- заполнение окна (контент не должен оставлять пустоту внизу);
- выравнивание чекбоксов по левому краю.

Пересчитать: размеры берутся из кода, окно 560×330 при scale = H/480.
