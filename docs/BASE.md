# База проекта

Начиная с этого коммита основой служит **gold-sdk** (`gold-sdk.zip`
в корне репозитория), а не прежняя самописная база.

## Почему переехали

Старая база накопила дефекты, которые чинились по одному и не
чинились: меню с конфликтами ID, курсор, который игра отбирала
каждый кадр, третье лицо на двух конкурирующих механизмах, 32
функции включённые по умолчанию.

## Чем новая база лучше (проверено)

| | старая | новая |
|---|---|---|
| дублей ID в меню | 6 | **0** |
| полей «только в меню» | 3 | **0** |
| включено по умолчанию | 32 функции | **4** (esp: box, name, enemies_only) |
| третье лицо | 2 механизма дерутся | **1** (vieworg в V_CalcRefdef) |
| курсор | Win32, отбирается | **SDL2 каждый кадр** + фолбэк на ImGui |

## Сборка

`bash build.sh` — 52 объекта, `x86-windows-gnu`.

**Только x86.** Под x86_64 структуры выходят больше (void* 8 байт
вместо 4): `cl_entity_t` даёт 3016 вместо 3000, и все смещения
уезжают — чит читает чужие поля. Проверено через static_assert.

## Что пришлось поправить в самом референсе

1. **`_ReturnAddress()`** — интринсик MSVC, в clang/zig нет.
   Заменён на `__builtin_return_address(0)`.
2. **`cursor::resolve()`** ставил `resolved = true` ДО проверки
   наличия SDL2. Если DLL не загружена на момент инжекта — курсор
   не заработал бы никогда. Теперь флаг ставится только при успехе.
3. **Третье лицо.** `on_is_third_person` возвращал `1`, включая
   РОДНОЕ третье лицо движка, а `third_person::apply()` рядом
   двигал `vieworg`. Два механизма за одну камеру — она
   проваливалась вниз, мышь крутила углы. Теперь только свой.
4. **`third_person::apply`** проверял `enabled`, но не `active`
   (в отличие от `on_is_third_person`).
5. **7 дублей ID** в меню (`behind walls` x3, `fov` x3, `enabled`,
   `distance`, `enemies only`, `hitbox`, `material`) — разведены
   через `##`.
6. **`sprites.cpp`** не был включён в `.vcxproj` — линковка падала.
