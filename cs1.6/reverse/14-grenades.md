## 1. Формула броска — точно ⭐

```c
// wpn_hegrenade.cpp:184 (WeaponIdle при отпускании)
Vector angThrow = m_pPlayer->pev->v_angle + m_pPlayer->pev->punchangle;

if (angThrow.x < 0)
    angThrow.x = -10 + angThrow.x * ((90 - 10) / 90.0);   // смотрим вверх
else
    angThrow.x = -10 + angThrow.x * ((90 + 10) / 90.0);   // смотрим вниз

float flVel = (90.0f - angThrow.x) * 6.0f;

if (flVel > 750.0f)
    flVel = 750.0f;

UTIL_MakeVectors(angThrow);                                // уже с поправкой

Vector vecSrc   = origin + view_ofs + forward * 16;
Vector vecThrow = forward * flVel + m_pPlayer->pev->velocity;

m_pPlayer->ThrowGrenade(this, vecSrc, vecThrow, 1.5, ...);
```

### Ключевые моменты

1. **`punchangle` входит в угол броска** — отдача влияет на дальность.
   Значит aimbot, гасящий отдачу, заодно делает бросок стабильным.
2. Угол **пересчитывается** в «нормализованный»: `angThrow.x` после
   преобразования лежит в `[-90, +90]`, но смысл перевёрнут — **чем
   больше `x`, тем слабее бросок** (потому что смотрим вниз).
3. Скорость: `flVel = (90 - angThrow.x) * 6`, максимум 750.
4. К скорости **прибавляется скорость игрока** — вот откуда «super toss».
5. Стартовая точка — `origin + view_ofs + forward*16` (не глаз, а 16
   вперёд).

### Таблица скоростей (проверено расчётом)

| куда смотрит | `angThrow.x` | скорость |
|---|---:|---:|
| вверх 90° | -90 | 750 (кап) |
| вверх 45° | -45 | 750 (кап) |
| вверх 20° | -20 | 750 (кап) |
| горизонт | 0 | **600** |
| вниз 10° | +10 | 540 |
| вниз 45° | +45 | **300** |
| вниз 90° | +90 | 0 |

Значит **кап 750 достигается уже при ~28° вверх** и держится до 90°.
Отсюда вывод: бросать «вверх сильнее» бессмысленно — дальше 750 нет.

## 2. Гравитация

```c
// pm_shared.cpp:2403
void PM_AddGravity()
{
    float ent_gravity = (pmove->gravity != 0.0f) ? pmove->gravity : 1.0f;
    pmove->velocity[2] -= ent_gravity * pmove->movevars->gravity * pmove->frametime;
    pmove->velocity[2] += pmove->basevelocity[2] * pmove->frametime;
    pmove->basevelocity[2] = 0;
}

// dlls/world.cpp:283
CVAR_SET_STRING("sv_gravity", "800");
```

`sv_gravity = 800` юнитов/с². **Без множителя 0.5** — применяется
целиком каждый кадр.

## 3. Траектория и оптимальный угол ⭐

Интегрирование `dt = 0.05` (тик 20 Гц — как у `PM_Move`):

```
v.z -= 800 * dt
p  += v * dt
```

### Дальность по углу (старт с высоты 64, приземление на 0)

| угол вверх | скорость | дальность |
|---:|---:|---:|
| 0° | 600 | 240 |
| 10° | 653 | 360 |
| 20° | 707 | 531 |
| 30° | 750 | 701 |
| **42°** | 750 | **764** ← оптимум |
| 50° | 750 | 742 |
| 60° | 750 | 641 |
| 80° | 750 | 250 |

**Оптимум — 42° вверх.** Не 45°, как обычно думают: из-за капа 750 при
бросании выше 28° скорость уже не растёт, а угол растёт — и оптимум
смещается вниз от 45°. Плюс стартовая высота 64 добавляет дистанции.

Это точный индикатор, который полезно рисовать в меню: он показывает
**реальную** дальность текущего угла, а не «на глаз».

## 4. Урон по радиусу

```c
// radius damage: линейное падение до нуля
damage = base * (1 - distance / radius)
```

Для HE-гранаты: `radius = 350`, `base = 100` (максимум по центру).
Значит на 200 юнитах урона 43, на 300 — 14, на 350 — 0.

Плюс сервер проверяет **видимость** от центра до цели (трассер); за
стеной урон не проходит вовсе. Это важно: нарисованный на клиенте
радиус ≠ реальный урон.

## 5. «Super toss» — что это на самом деле

Формула: `vecThrow = forward * flVel + player_velocity`.

Значит прибавка — **вектор скорости игрока целиком**, а не только
вперёд. Отсюда реальные способы:

| способ | прибавка |
|---|---|
| бег вперёд на 250 | +250 по направлению бега |
| прыжок с bhop | до +300 (кап 1.2*maxspeed) |
| падение с высоты | скорость падения по Z |

**Ключ:** скорость берётся **в момент отпускания**, а не броска
`m_flStartThrow`. Поэтому чит делает так:

```c
if (weapon_is_grenade() && cmd->buttons & IN_ATTACK)
{
    if (pm->velocity.z < 0.0f)          // падаем
        cmd->buttons |= IN_JUMP;        // прыгаем -> velocity.z растёт
}
```

Прыжок за кадр до отпускания даёт `+velocity.z ~ +270` к броску — это и
есть «super toss». Вверх, а не вперёд, потому что вперёд уже есть
`flVel`.

**Ограничение:** `pm->velocity` срезается `PM_PreventMegaBunnyJumping`
при `1.2 * maxspeed`, поэтому выше ~300 прибавки не получить.

## 6. Что реализовано в SDK

`src/features/sh_grenade.cpp`:

```c
f32 sh_grenade_launch_speed(f32 pitch);            // формула 1:1
void sh_grenade_predict(origin, angles, velocity, out);  // траектория 96 точек
f32 sh_grenade_range(f32 theta_up, f32 start_z);   // дальность по углу
f32 sh_grenade_optimal_angle(void);                // 42 град
void sh_grenade_damage_radius(center, victim, base, radius, out);
```

Проверка на реальных числах:

```
pitch  -90 -> v=750
pitch  +45 -> v=300
pitch  +90 -> v=0
42 град вверх -> дальность 764 юнита
```

## 7. Что ещё есть в гранатах (для полноты)

| граната | особенность броска |
|---|---|
| `CHEGrenade` | базовая, `flVel` по формуле выше |
| `CFlashbang` | та же формула, `radius 250`, слепота по углу взгляда |
| `CSmokeGrenade` | та же, дым через 1.5 с, радиус 350 |
| `CBreakable` (C4) | не бросается, ставится |

Флешка и дым используют **ту же** `WeaponIdle` логику — значит
`sh_grenade_launch_speed` верна для всех трёх.
